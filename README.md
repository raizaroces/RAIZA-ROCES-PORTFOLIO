## 🏗 Architecture & Section Flow

The single-page application follows a focused six-section chronological flow:

1. **Home (Hero)**: Value proposition, professional introduction, statistics overview, and immediate access to primary actions.
2. **Featured Projects**: Showcase of seven verified applications with category filters, technology stacks, live deployments, and interactive screenshot galleries.
3. **Technical Skills**: Structured inventory of programming languages, frameworks, databases, and engineering tools with interactive category filters.
4. **Core Strengths & Work Ethics**: Industry-aligned professional competencies and engineering values.
5. **Credentials**: Verified certificate gallery categorized into Cloud & DevOps, AI & Machine Learning, IT Infrastructure, and Professional & Specialization. Includes multi-credential group carousels, document previews, and full modal inspection.
6. **Contact**: Form submission with real-time client-side validation, dual-layer delivery fallback, and direct communication channels.

## 📬 Contact Architecture & Email Handling

The contact form features a resilient dual-layer delivery pipeline:

```text
Visitor Submits Form
         │
         ▼
┌─────────────────────────────────┐
│ Client Validation (Name, Email, │
│ Subject, Message length)        │
└────────────────┬────────────────┘
                 │
                 ├──► [Layer 1] POST /api/contact (Vercel Serverless Function)
                 │         │
                 │         ├── Has RESEND_API_KEY? ──► Sends Branded HTML Email via Resend
                 │         └── Unavailable / No Key? ─► Falls back to Layer 2
                 │
                 └──► [Layer 2] POST FormSubmit AJAX
                           │
                           └── Dispatches directly to raizaroces2800@gmail.com
```

- **Recipient Address**: `raizaroces2800@gmail.com`
- **Fallback**: One-click direct `mailto:` handler if client networks restrict external form submissions.

## ⚙️ Local Development & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.x or later)
- [npm](https://www.npmjs.com/) (version 9.x or later)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/raizaroces/RAIZA-ROCES-PORTFOLIO.git
   cd RAIZA-ROCES-PORTFOLIO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```

## 🌐 Deployment Guidelines

### Deploying to Vercel (Recommended)
1. Push your latest code to GitHub.
2. Sign in to [Vercel](https://vercel.com) and import the repository.
3. Keep default settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. *(Optional)* To enable Resend HTML email delivery, add this environment variable:
   - `RESEND_API_KEY`: Your key from [resend.com](https://resend.com)
5. Click **Deploy**.

### Deploying to GitHub Pages
1. Build the production bundle:
   ```bash
   npm run build
   ```
2. Configure GitHub Pages in your repository settings to serve the build from the `dist` branch or folder via a GitHub Action. The contact form will automatically use FormSubmit without requiring backend setup.
